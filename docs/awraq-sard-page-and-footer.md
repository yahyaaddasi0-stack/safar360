# أوراق سرد والفوتر العام

## المصادر التي استند إليها التنفيذ

- صفحة أوراق سرد المنشورة: <https://sard360.com/awraq-sard/> (صفحة WordPress رقم 2964، كانت تستدعي `[awraq_sard_main_page]`).
- سينما سرد: <https://sard360.com/cinema/>.
- كتالوج فيديوهات Cinéma Sard المنشور: <https://safar360-alpha.vercel.app/cinema.json>.
- واجهة REST العامة للمقالات: <https://sard360.com/wp-json/wp/v2/posts>.
- واجهة REST العامة للتصنيفات: <https://sard360.com/wp-json/wp/v2/categories>.
- الصفحة الرئيسية: <https://sard360.com/>.

## تصنيفات أوراق سرد الأساسية

تُستخدم هذه التصنيفات السبعة في الفوتر، وتُحوّل إلى أرشيفات WordPress مباشرة:

| التصنيف | الرابط |
|---|---|
| آفاق | `/cat-awraq/afaq/` |
| الآثار والاكتشافات | `/cat-awraq/athar/` |
| الأدب والفنون | `/cat-awraq/artsl/` |
| التاريخ والوقائع | `/cat-awraq/history/` |
| الشعوب والأنثروبولوجيا | `/cat-awraq/anthropology/` |
| الفلسفة والفكر | `/cat-awraq/philosophy/` |
| الموسيقى والأنغام | `/cat-awraq/musicology/` |

«سرد8» سلسلة تحريرية منفصلة تظهر في مرشحات المكتبة، وليست ضمن قائمة الموضوعات السبعة الأساسية في الفوتر.

## تصنيفات سينما سرد

تُطابق أسماء الفئات الستة في بيانات `cinema.json`: ذوات، تاريخ وحضارات، أدب وقراءات، تحقيقات كبرى، علوم وطبيعة، أجواء وموسيقى. روابط الفوتر تفتح `/cinema/?category=...`؛ ويقرأ المقتطف العام قيمة `category` ويختار مرشح السينما المطابق.

## الملفات المنشورة

- `wordpress/awraq-sard-shortcode.php`: مصدر shortcode `[awraq_sard_main_page]` الذي يعرض أحدث المقالات ومرشحات الموضوع والبحث والترشيحات.
- `wordpress/sard360-footer-categories.php`: مصدر المقتطف العام الذي يصحح روابط عناوين الفوتر وأقسامه ويوجه deep links إلى مرشحات السينما.

تُسحب المقالات من WordPress في وقت التصيير باستخدام روابط المقالات الأصلية والصور البارزة؛ لا تُنشأ permalinks يدوياً.
